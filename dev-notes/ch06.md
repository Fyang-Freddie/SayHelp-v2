## 核实方法

- 主 README（`https://github.com/FlagOpen/FlagEmbedding`）已不再内嵌完整 API 示例，
  只列出模型名（BGE-M3、bge-reranker-v2-m3 等），故改用仓库 tag `v1.4.2` 的源码文件核实。
- 版本确认：PyPI `FlagEmbedding` 最新版为 1.4.2；`requirements.txt` 锁定 `FlagEmbedding>=1.3`
  会解析到 1.4.x。`v1.4.2` 的 `FlagEmbedding/inference/__init__.py` 仍导出
  `BGEM3FlagModel` 与 `FlagReranker` 两个名字（向后兼容别名）。

## 1. BGEM3FlagModel（BGE-M3 嵌入）

- 源：`https://raw.githubusercontent.com/FlagOpen/FlagEmbedding/v1.4.2/FlagEmbedding/inference/embedder/encoder_only/m3.py`
- 导出别名：`FlagEmbedding/inference/embedder/encoder_only/__init__.py` 中
  `from .m3 import M3Embedder as BGEM3FlagModel`。
- 构造签名（节选）：
  ```python
  def __init__(
      self,
      model_name_or_path: str,
      normalize_embeddings: bool = True,
      use_fp16: bool = True,
      ...
      return_dense: bool = True,
      return_sparse: bool = False,
      return_colbert_vecs: bool = False,
      truncate_dim: Optional[int] = None,
      **kwargs: Any,
  ):
  ```
  注意：第一个参数名是 `model_name_or_path`（不是 `model_name`）。我们封装层
  `BGEM3Embedder(model_name=...)` 把 `self.model_name` 作为第一个**位置参数**传入，
  因此参数名差异不影响使用。
- `encode()` 返回类型（m3.py 内 `encode` 的 docstring 原样）：
  ```
  Dict[Literal["dense_vecs", "lexical_weights", "colbert_vecs"],
       Union[np.ndarray, List[Dict[str, float]], List[np.ndarray]]]
  ```
  → 稠密向量取 `out["dense_vecs"]`（`numpy.ndarray`，shape `(n, dim)`），
  封装层用 `.tolist()` 转为 `list[list[float]]`。

### 稠密维度 = 1024 的独立佐证

- BGE-M3 模型配置（HuggingFace 官方模型卡配置文件）：
  `https://huggingface.co/BAAI/bge-m3/resolve/main/config.json`
  实测字段 `hidden_size = 1024`（`model_type = xlm-roberta`），即 dense_vecs 维度 1024。

## 2. FlagReranker（bge-reranker-v2-m3 精排）

- 源：`https://raw.githubusercontent.com/FlagOpen/FlagEmbedding/v1.4.2/FlagEmbedding/inference/reranker/encoder_only/base.py`
  （`FlagReranker` 是 `BaseReranker` 的别名，见
  `FlagEmbedding/inference/reranker/encoder_only/__init__.py` 及相关导出）
- 构造签名（节选）：
  ```python
  def __init__(
      self,
      model_name_or_path: str,
      use_fp16: bool = False,
      ...
      normalize: bool = False,
      **kwargs: Any,
  ):
  ```
- `compute_score`（定义于 `abc/inference/AbsReranker.py`，节选签名与行为）：
  ```python
  def compute_score(
      self,
      sentence_pairs: Union[List[Tuple[str, str]], Tuple[str, str]],
      **kwargs
  ):
  ```
  - 入参形状：**句对列表**，即 `[[query, passage], [query2, passage2], ...]`。
    若传单个 `(query, passage)` 元组（`sentence_pairs[0]` 为 str），内部自动包成单元素列表。
  - 返回类型：`List[float]`（单设备路径 `compute_score_single_gpu` 用
    `scores.cpu().numpy().tolist()` 返回 `List[float]`；`normalize=True` 时经 sigmoid）。

## 实现映射（app/rag/bge.py）

| 协议/类 | 底层调用 |
|---|---|
| `BGEM3Embedder.encode_dense(texts)` | `BGEM3FlagModel(self.model_name, use_fp16=...).encode(texts, return_dense=True, return_sparse=False, return_colbert_vecs=False)["dense_vecs"].tolist()` |
| `BGEReranker.rerank(query, passages)` | `FlagReranker(self.model_name).compute_score([[query, p] for p in passages])` |

- `embedding_use_fp16` 来自 `app.config.settings`（默认 `False`），在**首次调用时**才读取。
- 两类的 `__init__` 只存 `model_name` 并置 `model = None`，不 import FlagEmbedding/torch，
  不触发任何下载 —— 保证测试 `dim == 1024`、`model is None` 在未安装依赖时也能通过。
