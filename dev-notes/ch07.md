    SecretStr | None | Callable[[], str] | Callable[[], Awaitable[str]]

## 3. with_structured_output 签名（ChatOpenAI 1.7.2 覆盖版，源码原文）

```python
def with_structured_output(
    self,
    schema: _DictOrPydanticClass | None = None,
    *,
    method: Literal["function_calling", "json_mode", "json_schema"] = "json_schema",
    include_raw: bool = False,
    strict: bool | None = None,
    tools: list | None = None,
    **kwargs: Any,
) -> Runnable[LanguageModelInput, _DictOrPydantic]:
```

- 返回一个 **Runnable**，用 `.invoke(messages)` 调用（`messages` 可为
  `[{"role": "user", "content": ...}]` 这类消息列表）。
- `schema` 传 **dict（JSON Schema）** 且 `include_raw=False` 时，`.invoke()` 返回 **dict**；
  传 Pydantic 模型时返回该模型实例。→ 与本任务 `complete_json(...) -> dict` 一致。
- `method` 默认值：`ChatOpenAI` 覆盖版为 `"json_schema"`（基类 `BaseChatModel` 为
  `"function_calling"`）。本任务不显式传 `method`，使用库默认值。

## 4. complete 的返回形态

`ChatOpenAI.invoke(messages)` 返回 `AIMessage`，文本取 `.content`（str）。

## 5. 关于 use_responses_api=False 的裁决

官方参考文档在「OpenAI 兼容端点」一节给出示例并注明：对兼容提供商应显式设置
`use_responses_api=False`，避免误走 OpenAI 专属的 Responses API：

```python
model = ChatOpenAI(
    base_url="http://localhost:8000/v1",
    api_key="EMPTY",
    model="meta-llama/Llama-2-7b-chat-hf",
    use_responses_api=False,
)
```

`app/config.py` 的 `chat_base_url` / `jev_base_url` 指向的是兼容网关而非 api.openai.com，
因此 `OpenAIChatModel` 与 `JevIntentModel` 均显式传 `use_responses_api=False`，
走最通用的 chat.completions 协议。

## 实现映射（app/llm/client.py）

| 协议/类 | 底层调用 |
|---|---|
| `OpenAIChatModel.complete(messages)` | `ChatOpenAI(model, base_url, api_key, use_responses_api=False).invoke(messages).content` |
| `OpenAIChatModel.complete_json(messages, json_schema)` | `ChatOpenAI(...).with_structured_output(json_schema).invoke(messages)`（dict 进 dict 出） |
| `JevIntentModel.classify(text)` | `ChatOpenAI(model=settings.jev_model, base_url=settings.jev_base_url, api_key=settings.jev_api_key, timeout=settings.intent_timeout_s, use_responses_api=False).with_structured_output(INTENT_SCHEMA).invoke(messages)` → `IntentResult` |

- 两个真实模型的 `__init__` 只存参数并置 `_llm = None`，不 import langchain_openai；
  `_get_llm()` 在首次调用时延迟导入并实例化 —— 保证测试在未安装依赖时也能通过。
- `intent_timeout_s`（`app/config.py`，默认 10）在 `classify()` 首次调用时才经
  `from app.config import settings` 读取。
